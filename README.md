# Kris — 个人博客

纯静态的个人站点。纸白底、墨黑字，衬线正文配等宽元信息，只有发丝线，没有阴影和动画。

线上地址：**https://kriswang.me**

## 怎么看

直接用浏览器打开 `index.html` 就行，不需要构建、不需要装任何东西。

想在本地连上接口看内容：

```bash
cd site
npm run dev
```

浏览器打开命令输出的本地地址。静态页面单独打开时读不到数据库里的内容。

## 直接改页面

正文在后台里写。标记支持空一行分段、`## 小标题`、`> 引用`、`- 列表`、`**粗体**`、`` `代码` ``，图片写成 `![说明](/media/文件名)`。

**改名字**：全局搜索 `Kris`，替换成你的名字。涉及标题、导航、页脚。

**换头像**：把 `assets/img/avatar.svg` 换成你的照片，或者直接改各页面 `<link rel="icon">` 指向新文件。

**改配色**：打开 `assets/css/style.css`，最上面的 `:root` 就是全部颜色变量。
`--paper` 是纸色，`--ink` 是标题色，`--body` 是正文色，`--muted` 是日期、说明这类次要信息。

**改字体**：同样在 `:root` 里的 `--font-serif / --font-sans / --font-mono`。
中文默认走系统字体（Mac 的苹方/宋体、Windows 的微软雅黑/思源），
英文走 Google Fonts 的 Source Serif 4 / Inter / IBM Plex Mono。断网时会自动回退，不会崩。

## 首屏短句

首页顶部每次刷新随机显示一句，取自 `assets/js/quotes.js`。

首屏占满一屏（`min-height: calc(100svh - var(--nav-h))`），下面三个区块要往下滑才看得到。

- 结构：`{ text: 原文, author, source, lang?, zh? }`
- `lang` 是原文语言（`de`/`fr`/`en`/`da`），`zh` 是中文译文——**有 `zh` 才会出现「译」按钮**
- 纯中文的句子不要写 `lang` 和 `zh`，只显示原文
- 点「译」时原句上浮淡出、译文自下淡入（各 260/300ms）；再点一次换回原文，按钮变成「原」
- 同一台设备不会连续抽到同一句（`sessionStorage` 记上一次）

想加句子直接往数组里加一条；想删就把那一行删掉。改完记得升 `?v=` 版本号。

## 交互

- 关于页标题下的那一排社交图标：入场按 55ms 错位淡入；鼠标进入时其余图标淡到 30%，
  被指的那个回到墨色并上浮 2px。图标是 40px 细线圆环，内容在 `about.html` 的 `.sicons` 块里，
  增删一个平台复制/删除一个 `<a class="sicon">` 即可，`style="--i:序号"` 决定入场顺序。
- **页面转场**：点站内链接时**正文和页脚**淡出 0.2s 再跳转，新页 0.34s 淡入；
  导航栏不参与，始终留在原位。只拦普通左键点击，新标签页、下载、`mailto:` 都不受影响。
- **自定义光标**：桌面端隐藏原生指针，换成跟随的小墨点（缓动 0.18）；指到链接、按钮、照片时绽开一个 38px 细圆环。
  触屏、`prefers-reduced-motion`、以及编辑面板内都不启用。想关掉：删掉 `main.js` 里的 `initCursor()` 调用。
- **时间线**：导航里的「时间线」页。后台保存文章、手记、关于，或删除它们时，会自动加一条节点，最新在最上。
- **正文插图**：后台写文章或手记时可点「插入图片」，也可把截图粘贴进正文，或拖进输入框。图片存到 R2，正文里是 `![说明](/media/…)`。
- **首屏视差**：鼠标在首屏移动时，引文整体反向位移最多 7px，缓动 0.08，移出首屏回中。
- **首屏水墨**：在首屏空白处点一下，像低头看一盆清水里滴进一滴墨——墨被几股方向随机的水流推开，
  长出不对称的瓣，瓣头卷成小涡，再被暗流拉成细丝慢慢漂开变淡，约 7 秒散尽；墨浓的地方透出藏在底下的山水。
  水和墨用 WebGL2 按流体演算（`assets/js/ink.js`），手感参数都在文件开头「手感」一节。
  引文底下的墨会自动减淡（大字处最多 42%、出处最多 7%），保证字始终看得清。
  浏览器不支持 WebGL2 或开了「减少动态效果」时不启用，页面照常显示。
  想关掉：删掉 `index.html` 里引入 `ink.js` 的那行；改了 `ink.js` 记得升 `?v=` 版本号。
  山水底图是 Lingdong Huang《{Shan, Shui}*》生成的一帧（MIT 协议）。
- **导航黑线**：当前页那条黑线在切页时会从原来那一项滑到新的那一项（0.42s），
  悬停任何一项它也会先滑过去，移开后回位。跨页滑动靠 sessionStorage 记上一页的位置。
- **滚动进入**：区块和列表项进视口时上浮 10px 淡入，只跑一次；列表项按 45ms 错位。
  依赖 `html.js` 这个类——JS 没跑起来时内容保持可见，不会白屏，另有 1.6 秒兜底。
- **导航**：悬停时下划线从左往右长出来，当前页常亮。
- **列表**：鼠标划过文章/手记条目时底色极浅地压一下。
- **照片灯箱**：淡入 + 图片从 98.5% 微放大。
- 窄屏时导航收进右上角按钮，点开是纵向菜单，`Esc` 关闭。
- 照片墙点开是大图，支持 `←` `→` 翻页、`Esc` 关闭，三栏按图片高度自动配平。
- 系统开了「减少动态效果」（`prefers-reduced-motion`）时，以上动画全部关掉，内容直接显示。
